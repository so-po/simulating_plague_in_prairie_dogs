## (Optional) Using a virtual environment:

### First-Time Setup:
1. Create the virtual environment:

    ``python3 -m venv <venv name>``

    This will create a new directory for the virtual environment. **Do not commit this directory to the repo!** It will clutter things up.

2. Enter the virtual environment:

    - On Mac:
        
        ``source <venv name>/bin/activate``
    - On Windows:
        
        ``<venv name>/bin/activate``

3. Install all necessary packages:

    ``pip install -r required_packages.txt``

4. Now you can use python normally and it will use the packages from the virtual environment!

5. When you're done, deactivate:

    ``deactivate``
